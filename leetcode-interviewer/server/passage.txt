Can the array be empty, and can I use the same element twice? A brute force approach checks every pair, which is O of n squared time. A better approach uses a hash map. For each number, I check whether the complement is already in the map. If it is, I return both indices. Otherwise, I store the number with its index. That is one pass, so O of n time and O of n space. Let me trace it with two, seven, eleven and fifteen, and a target of nine.
